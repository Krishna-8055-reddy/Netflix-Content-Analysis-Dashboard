📊 Netflix Movies & TV Shows Dashboard (Tableau)
🎬 Overview

This project analyzes Netflix’s global catalog of Movies and TV Shows using a fully interactive Tableau dashboard.
It provides insights into content distribution across countries, genre popularity, ratings, type breakdown, and year-wise content trends from 2008–2020.

The goal is to visually understand how Netflix’s content library has evolved and how it varies across regions and categories.

🚀 Key Features

🌍 Global Content Map
Country-wise distribution of Movies & TV Shows using a geospatial world map.

📺 Movies vs TV Shows Breakdown
Bubble chart highlighting the share of Movies (68%) versus TV Shows (32%).

⭐ Ratings Analysis
Bar chart showing the frequency of content rating categories (TV-14, TV-MA, PG, etc.).

🎬 Top 10 Genres
Horizontal bar chart showing the most popular genres across Netflix.

📅 Yearly Trends (2008–2020)
Area chart visualizing the growth of Movies and TV Shows over time.

🔎 Dynamic Filters
Type, Title, Genre, and Rating slicers for flexible insights and deeper exploration.

📝 Title-Level Details
Metadata including rating, release year, duration, genre, and description displayed dynamically.

🛠️ Tools & Technologies Used

-> Tableau Desktop / Tableau Public (Dashboard Creation)

-> Tableau Maps (Geospatial Visualization)

-> Calculated Fields (Type split, Year buckets, Genre grouping)

-> Excel for data cleaning
